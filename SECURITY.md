# Security policy

Please do not disclose vulnerabilities or credentials in public issues or pull requests. Use the repository's GitHub Security tab and **Report a vulnerability** to submit a private report, including reproduction steps and potential impact. The maintainer will coordinate investigation and disclosure through that report. If private vulnerability reporting is unavailable, contact the repository owner privately through a trusted existing channel; do not post the details publicly. A dedicated private security contact remains to be chosen before production.

The current development and production branches are `dev` and `main`. Fixes are assessed against both branches.
